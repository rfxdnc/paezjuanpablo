# 🛍️ Ecommerce Talento Tech

Sitio web de ecommerce desarrollado con HTML5 y CSS3 puro. Incluye página de inicio, catálogo de productos, formulario de contacto y carrito de compras.

## 🚀 Tech Stack

## 📁 Estructura

```
ecommerce/
├── index.html
├── styles.css
├── contacto.html
├── contacto.css
├── tienda.html
├── carrito.html
└── img/
```

## ✨ Features

- Diseño responsive con Flexbox y CSS Grid
- Navbar con menú hamburguesa para mobile
- Cards de productos con hover effects
- Sección de reseñas con Grid de 3 columnas
- Formulario de contacto integrado con Formspree
- Mapa embebido con Google Maps iframe
- Newsletter con diseño oscuro

## 📸 Vistas

| Sección | Descripción |
|---|---|
| Home | Hero, productos destacados, reseñas, newsletter |
| Tienda | Catálogo completo de productos |
| Contacto | Formulario, equipo y mapa de ubicación |
| Carrito | Resumen de compra |
